##Forma de uso
Tener lista de nombres separados por comas ',' y pegar y directamente los separa y realiar sorteo. 
Esta diseñada para ser responsiva con smarthphones.

## HTML de amigo secreto

Este realiza el sorteo y tiene en cuenta de no generar 'islas' de personas que se saquen mutuamente ni a sí mismos. 

## HMTL de amigo goloso

Genera un PDF con el nombre de gustos y no gustos para compartir, funciona con tarjetas para pasar celular de persona a persona para evitar que alguien modifique el de otra persona y genera un checkeo en verde para saber quienes ya pusieron sus gustos y no gustos.
